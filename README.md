# Azure Vianet VPN Gateway Resilience with BGP

> PowerShell scripts to configure a resilient Azure VPN Gateway connection to Azure Vianet using BGP and custom IPSec policies for dynamic routing and improved stability.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/azure-vianet-vpn-bgp-resilience.git
cd azure-vianet-vpn-bgp-resilience

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Azure

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
